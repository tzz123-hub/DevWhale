# 测试铁律

> 此后所有功能测试必须满足以下标准，无例外。

## 核心原则

**每项功能必须经过"真实实例操作"验证，禁止 mock / stub / fake。**

## 操作标准

| 功能模块 | 必须执行的真实操作 |
|---------|-------------------|
| Skills | 从 BUILTIN_SKILLS 加载 → 启用/禁用 → 安装自定义 → 卸载 → 查询聚合 |
| MCP | 注册会话 → 路由解析 → 工具调用 → 停止会话 → 错误路径 |
| 文件 I/O | 创建真实临时文件 → 写入内容 → 读取验证 → 删除清理 |
| Shell | 执行真实系统命令 → 验证 stdout/stderr → 验证退出码 |
| 存储 | 真实 localStorage 读写往返 → 损坏数据恢复 → 边界值 |
| 路径解析 | 真实 Windows 路径 → 跨平台规范化 → 边界格式 |
| Checkpoint | 写入文件 → 创建检查点 → 修改文件 → 回滚 → 验证内容 |
| Diff 解析 | 真实 git diff 输出 → 解析 → 验证行类型和内容 |

## 验证铁律

1. **不得使用 vi.fn() / mock / spy 验证核心功能路径**
2. **每个测试必须产生可观测的副作用（文件存在、命令输出、localStorage 值）**
3. **测试结束后必须清理副作用（删除临时文件、清除测试数据）**
4. **三遍运行结果必须完全一致（零随机失败）**

## 运行命令

```bash
npm run test:real    # 真实实例全功能测试
```
